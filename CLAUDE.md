# JAMM PX — Standing Instructions

Before writing or executing any task involving the Concierge agent (backend routes, prompts, frontend chat UI, tools, or knowledge corpus), read these two files in full first:

1. JAMM_PX_Perfect_Assistant_Build.md — the standard the Concierge is being built toward. Every Concierge related task should be traceable to something described in this document.
2. How_We_Work_Process_Rules.md — the process rules for how work gets verified, debugged, and scoped in this repo.

Do not skip reading these because a task looks small or well understood. They contain hard-won context that is not obvious from the code alone.
