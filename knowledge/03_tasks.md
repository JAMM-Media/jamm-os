## Tasks > Overview > What a Task Is

A task is a single action item that belongs to an engagement. Tasks represent the individual steps required to complete an engagement. Every task is linked to both a client and an engagement.

Tasks are also called to-dos, checklist items, or action items in some other practice management tools. In JAMM PX the term is always task.

Create the engagement before creating a task. A task must be linked to an engagement and cannot exist without one.

---

## Tasks > Overview > Task Statuses

Every task has one of three statuses.

To Do means the task has not been started. This is the default status when a task is created.

In Progress means work on the task has begun but is not finished. Move a task to in progress when a staff member is actively working on it.

Done means the task is complete. Moving a task to done also marks it as completed in the system.

---

## Tasks > Creating a Task > How to Create a Task

Navigate to Tasks in the left sidebar and click New Task. You can also create a task from inside an engagement by opening the engagement detail page and selecting the Tasks tab, then clicking New Task.

Four fields are required before the task will save: the title, the client, the engagement, and the due date. The engagement list filters to show only engagements belonging to the selected client. Select the client first and the engagement list populates automatically.

Assigning the task to a staff member is optional at creation. You can assign it immediately or leave it unassigned and assign it later.

---

## Tasks > Creating a Task > Required Fields

The task title is a short description of the work. Examples: Prepare depreciation schedule, Review prior year return, Send organizer to client.

The client field links the task to a client record. Select the client whose engagement this task belongs to.

The engagement field links the task to a specific engagement under that client. The engagement list shows only engagements for the selected client.

The due date is the date by which the task should be completed. Due date is required at creation and affects how tasks sort in the task list.

---

## Tasks > Creating a Task > Assigning a Task to a Staff Member

A task can be assigned to one staff member. Open the New Task modal and select a staff member from the Assigned To field. All active staff members on the firm appear in the list.

If no staff member is assigned, the task is visible to all staff with access to the Tasks module. Assigned tasks appear in the assigned staff member's personal task view.

You can assign or reassign a task after it is created by opening the task and editing the assigned staff field.

---

## Tasks > Creating a Task > Adding Notes to a Task

Open the New Task modal or edit an existing task to access the Notes field. Notes are internal only and are never shown to clients.

Use notes for preparer instructions, context about the task, or reminders for the assigned staff member.

---

## Tasks > Managing Tasks > The Task List

Navigate to Tasks in the left sidebar to open the task list. The list shows all tasks across all engagements for the firm.

The task list supports two views: table view and card view. Toggle between them using the view toggle in the top right of the task list. Table view shows tasks in rows with columns for title, client, engagement, due date, assigned staff, and status. Card view shows tasks as individual cards.

Tasks sort by due date in ascending order by default, with the earliest due dates at the top. Change the sort direction using the due date sort toggle.

---

## Tasks > Managing Tasks > Filtering the Task List

The task list has three filters: status, client, and a search field.

Filter by status to show only tasks in a specific status. Options are To Do, In Progress, and Done. Select All to clear the status filter.

Filter by client to show only tasks linked to a specific client.

Use the search field to find tasks by title. The search filters the list as you type.

The My Tasks toggle shows only tasks assigned to the currently logged in user. Staff role users have this toggle on by default. Firm owners and managers can toggle it on or off.

---

## Tasks > Managing Tasks > Changing a Task Status

Open a task and select a new status from the status field. The three options are To Do, In Progress, and Done.

You can also change a task status inline from the task list without opening the task. Click the status badge on the task row and select the new status.

When a task is marked Done it is also flagged as completed in the system. Completed tasks remain visible in the task list and can be filtered by their done status.

---

## Tasks > Managing Tasks > Editing a Task

Open the task from the task list or from inside the engagement. Click Edit to open the edit modal. You can change the title, status, due date, and notes from the edit modal.

To change the assigned staff member, open the task and update the assigned to field. The client and engagement a task belongs to can also be changed from the edit modal if the task needs to be moved.

---

## Tasks > Managing Tasks > Deleting a Task

Select one or more tasks in the task list using the checkboxes. With tasks selected, the bulk action toolbar appears. Click Delete in the bulk toolbar and confirm the deletion.

Deleting a task is permanent. The task and its notes are removed from the system. Deleted tasks cannot be recovered.

---

## Tasks > Bulk Actions > How Bulk Actions Work

Select multiple tasks by checking the checkbox on each task row. A bulk action toolbar appears at the bottom of the task list when one or more tasks are selected. The toolbar shows a count of selected tasks.

Bulk actions available: change status, reassign to a staff member, and delete.

To select all tasks currently visible in the filtered list, check the select all checkbox in the table header.

---

## Tasks > Bulk Actions > Bulk Status Change

Select the tasks you want to update. In the bulk action toolbar click the status button and select the new status. All selected tasks move to the new status immediately.

This is useful for closing out all tasks on a completed engagement or moving a group of tasks to in progress when a team begins a new phase of work.

---

## Tasks > Bulk Actions > Bulk Reassign

Select the tasks you want to reassign. In the bulk action toolbar click the reassign button and select a staff member. All selected tasks are reassigned to that staff member immediately.

Use bulk reassign when redistributing work between staff members or when a staff member leaves and their tasks need to be transferred.

---

## Tasks > Tasks Inside an Engagement > Viewing Tasks on an Engagement

Open any engagement and select the Tasks tab. The Tasks tab shows all tasks linked to that engagement. Creating a task from inside an engagement pre-fills the client and engagement fields automatically.

The engagement task view shows the same status, due date, and assignee information as the main task list. Use this view when you want to see the complete task picture for a single engagement without filtering the main list.

---

## Tasks > Tasks Inside an Engagement > Task Completion and Engagement Progress

Tasks on an engagement contribute to the overall progress picture for that engagement. As tasks move to done, the engagement reflects the completed work.

There is no automatic engagement status change when all tasks are done. The firm owner or assigned staff member changes the engagement status manually when the work is complete.
