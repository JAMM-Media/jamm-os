## Time Tracking > Overview > What Time Tracking Is

Time tracking in JAMM PX lets staff log hours worked against specific engagements. Every time entry is linked to an engagement, records the hours worked, the hourly rate, and whether the time is billable. Time entries feed directly into the WIP report and can be converted into invoice line items.

Navigate to Timesheets in the left sidebar to access all time tracking views.

---

## Time Tracking > Overview > Billable vs Non-Billable Time

Every time entry is marked as either billable or non-billable. Billable time counts toward the WIP report and can be added to an invoice. Non-billable time is tracked for internal visibility but does not appear in billing calculations.

Mark time as non-billable for internal work, admin tasks, or any time that should not be charged to the client.

---

## Time Tracking > Logging Time > How to Log a Time Entry

Navigate to Timesheets in the left sidebar. The Daily tab is the default view. Select the engagement the time was worked on. Enter a description of the work, the date, and either a start and end time or a direct hours value.

Required fields for a time entry: engagement, description, hours, hourly rate, and date. Start time and end time are optional. When start and end time are entered, JAMM PX calculates the hours automatically.

Select an activity type to categorize the work. Available activity types are Tax Preparation, Client Meeting, Document Review, Review and Sign-off, Client Communication, Research, Admin, and Other.

Mark the entry as billable or non-billable before saving.

---

## Time Tracking > Logging Time > Using the Timer

The Daily tab includes a live timer for tracking time as you work. Select an engagement and activity type, then click Start. The timer runs in real time and displays the elapsed hours, minutes, and seconds.

Click Stop when the work is complete. JAMM PX calculates the duration and pre-fills the time entry form with the start time, end time, and hours. Review and save the entry.

The timer persists if you navigate away from the Timesheets page. Only one timer can run at a time. Starting a new timer stops any timer already running.

---

## Time Tracking > Logging Time > Activity Types

Activity types categorize the nature of the work for reporting and visibility. Select the activity type that best describes what was done for that time entry.

The available activity types are: Tax Preparation, Client Meeting, Document Review, Review and Sign-off, Client Communication, Research, Admin, and Other. If none of the standard types fit, select Other and add detail in the description field.

Activity type is optional but recommended for firms that want to analyze how time is distributed across work categories.

---

## Time Tracking > Timesheet Views > Overview of Views

The Timesheets page has six views: Daily, Weekly, Biweekly, Monthly, Quarterly, and Yearly. Each view shows time entries aggregated for the selected period. Switch between views using the tab bar at the top of the Timesheets page.

Use the Daily view for logging and reviewing entries day by day. Use the Weekly or Monthly views for reviewing total hours per staff member or engagement over a period. Use the Quarterly and Yearly views for higher-level time analysis.

---

## Time Tracking > Timesheet Views > Filtering Time Entries

The Timesheets page has four filters that apply across all views.

Filter by billable status to show all entries, billable only, or non-billable only.

Filter by client to show only time logged against engagements for a specific client.

Filter by engagement to show only time logged against a specific engagement.

Filter by staff member to show time logged by a specific person. The staff filter is only available to firm owners and managers. Staff members see only their own time.

---

## Time Tracking > Submission and Approval > Submitting a Timesheet

Staff members submit their time entries for manager review. On the Daily tab, locate the entries for the day and click Submit. Submitted entries are flagged as submitted and sent to the manager or firm owner for approval.

Submitting time indicates that the staff member considers their entries complete and accurate for that period. Submitted entries can still be edited by a manager.

---

## Time Tracking > Submission and Approval > Approving Time Entries

Managers and firm owners can approve submitted time entries. Navigate to Timesheets and review submitted entries flagged for approval. Approve entries that are accurate. Approved entries are marked as approved and are eligible to be added to invoices.

If an entry needs correction after submission, a manager can edit it. Edited entries after submission are flagged as edited so the history is preserved.

---

## Time Tracking > Billing Integration > Converting Time Entries to an Invoice

Approved unbilled time entries can be added to an invoice directly. Navigate to the engagement the time was logged against. Select the option to create an invoice from time entries. Choose the entries to include. JAMM PX creates a draft invoice with those entries as line items and marks the included entries as billed.

Once a time entry is marked as billed, it no longer appears in the WIP report. Review the draft invoice before sending it to the client.

---

## Time Tracking > Billing Integration > The WIP Report

The WIP report shows all unbilled billable time across all active engagements. Navigate to Billing in the left sidebar and select WIP Report.

The report shows each engagement with its client name, total unbilled hours, and the dollar value based on the hourly rates logged. Use the WIP report before month-end billing to identify work that has been done but not yet invoiced.

Export the WIP report to CSV using the Export CSV button. The export includes client, engagement, hours, and value columns.
