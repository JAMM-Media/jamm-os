## Procedure: Tax Season Kickoff

TRIGGER: Tax season is beginning and the firm needs to activate intake workflows for all returning tax clients.

STEP 1: Confirm engagement templates are ready.
Navigate to Engagements and select Templates. Confirm templates exist for your most common return types: 1040, 1120-S, 1065, or whichever types your firm prepares. IF templates do not exist, create them now. Each template should include a standard task list and a document request checklist for that return type.

STEP 2: Create engagements for returning clients.
For each returning client, navigate to their client record, open the Engagements tab, and create a new engagement using the appropriate template. Set the title using the tax year and return type. Set the filing deadline. Assign the engagement to the preparer responsible for this client.
IF you have many clients, create engagements in batches by entity type to stay organized.

STEP 3: Send document requests.
Each engagement created from a template already has a document request checklist pre-filled. Navigate to each engagement, open the Document Requests tab, and confirm the checklist items are correct for that client. Add any client-specific items. Set a due date for document submission. Save the request. The client sees it immediately in their portal.

STEP 4: Send portal magic-links to clients who do not yet have portal access.
Navigate to Clients and review which clients do not have portal access enabled. Enable portal access for each and send a magic-link. Send magic-links in batches of 10 to 15 per day for the first week rather than all at once. This paces the volume of client questions your team receives as clients activate their portals for the first time.

STEP 5: Enable the 1040 Season Kickoff automation preset.
Navigate to Settings and select Automations. Find the 1040 Season Kickoff preset and enable it. This preset automatically sends a welcome email, creates a task to collect the prior year return, and creates a task to verify contact information when each new 1040 engagement is created.

STEP 6: Confirm IRS authorizations are current.
Navigate to each client record and check the IRS Authorizations section. Confirm active Form 8821 authorizations are on file for all tax clients whose transcripts you will pull. IF any authorizations are expired or missing, send a new authorization for signature before beginning transcript retrieval.

STEP 7: Enable the IRS Authorization Expiry Warning preset.
Navigate to Settings and select Automations. Confirm the IRS Authorization Expiry Warning preset is enabled. This fires when any active authorization approaches its expiry date and creates a renewal task automatically.
