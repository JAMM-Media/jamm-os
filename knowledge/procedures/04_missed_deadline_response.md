## Procedure: Missed Deadline Response

TRIGGER: An engagement deadline has passed and the engagement is not completed, an overdue engagement appears in the dashboard, or a staff member reports a missed deadline.

STEP 1: Assess the situation.
Open the engagement. Check the current status and the assigned staff member. Check which tasks are still open and which document request items are still pending. IF the engagement is close to done with only minor items remaining, proceed to STEP 2.
IF the engagement is significantly behind, proceed to STEP 3.

STEP 2: Fast-track completion.
Identify the specific blocking items. IF documents are still pending from the client, navigate to the Document Requests tab and click Send Reminder to prompt the client immediately. IF tasks are still open, open the task list and reassign any overdue tasks to the staff member with the most capacity. Set a new internal target date.
IF an extension is available and appropriate, proceed to STEP 5.

STEP 3: Determine if an extension applies.
Ask the firm owner whether an extension has been filed or can still be filed for this engagement. IF an extension was already filed, confirm the extended deadline is set on the engagement. Navigate to the engagement, click Edit, and verify the extended deadline field reflects the correct date. IF the extended deadline is not set, enter it now. END.
IF an extension has not been filed and the original deadline has passed, proceed to STEP 4.

STEP 4: File an extension if applicable.
IF the engagement type supports an extension and the extension deadline has not yet passed, create a new engagement for the extension filing (4868 for individual, 7004 for business). Assign it to staff, set the extension filing deadline, and prioritize completion before the extension itself expires.
After the extension is filed, update the original engagement with the new extended deadline. Proceed to STEP 2.

STEP 5: Update the engagement deadline.
Navigate to the engagement and click Edit. Update the extended deadline to the correct date. Save the change. The morning briefing and deadline tracking will use the new date going forward. Notify the client of the new deadline by adding a client-visible note to the engagement or sending a message through the portal Messages tab.

STEP 6: Log the missed deadline internally.
Add an internal note to the engagement documenting when the deadline was missed and what caused the delay. This note is never visible to the client. Use this information in your next team review.
