## Procedure: Client Cannot Upload Documents

TRIGGER: Firm owner says a client cannot upload documents, a client says they cannot upload a file, or a document request item has been pending for more than 7 days with no upload activity.

STEP 1: Confirm the client has portal access enabled.
Navigate to Clients and open the client record. Check the Portal Access section. IF portal access is disabled, enable it and send the client a new magic-link. END.
IF portal access is enabled, proceed to STEP 2.

STEP 2: Confirm the client received a magic-link.
Ask the firm owner: has a magic-link been sent to this client? IF no magic-link has been sent, navigate to the client record, open Portal Access, and send a magic-link. Tell the firm owner to direct the client to check their inbox and spam folder for the link. END.
IF a magic-link was sent, proceed to STEP 3.

STEP 3: Confirm the client is on the correct tab.
Ask the firm owner to have the client open their portal and look at the To-do tab. Document uploads happen from the To-do tab only. IF the client is on the Documents tab, direct them to the To-do tab and locate the document request card with the Upload button. END.
IF the client is on the To-do tab and still cannot upload, proceed to STEP 4.

STEP 4: Confirm the file type is supported.
Ask the firm owner what type of file the client is trying to upload. Accepted file types are PDF, Word documents (.doc and .docx), Excel files (.xls and .xlsx), PNG images, and JPG images. IF the file type is not on this list, ask the client to convert the file to PDF and try again. END.
IF the file type is supported, proceed to STEP 5.

STEP 5: Check for browser or device issues.
Ask the firm owner to have the client try uploading from a different browser. Chrome and Safari on a recent version are the most reliable. IF the upload works on a different browser, the original browser was the issue. Advise the client to use Chrome or Safari. END.
IF the upload fails on all browsers, proceed to STEP 6.

STEP 6: Use the manual upload workaround.
Ask the client to email the file directly to the firm. The firm owner uploads the file manually from the staff application. Navigate to the engagement, open the Document Requests tab, find the checklist item, and mark it as approved after uploading the file on the client's behalf. This resolves the item without the client uploading through the portal.
