## Procedure: New Client Onboarding End to End

TRIGGER: A new client has been added to JAMM PX and needs to be fully set up with an engagement, portal access, and a document request.

STEP 1: Create or confirm the client record.
Navigate to Clients and verify the client record exists with a name and email address. IF the client was just created and has no email address, open the client record and add their email before proceeding. An email address is required to send portal access.

STEP 2: Set the entity type.
Open the client record and confirm the entity type is set. Options are individual, business, trust, or estate. IF the entity type is not set, set it now. The entity type affects which engagement types and IRS authorization forms are appropriate.

STEP 3: Create the first engagement.
Open the client record and navigate to the Engagements tab. Click New Engagement. Select the engagement type that matches the first piece of work. If an engagement template exists for this type, select Use Template to pre-fill tasks and document request items. Set the title, end date, and assigned staff member. Save the engagement.

STEP 4: Send IRS authorization if this is a tax client.
IF the client is a tax client who will need transcript access, navigate to the client record and open the IRS Authorizations section. Click Send Authorization. Select Form 8821. Enter the tax years to cover. Send for e-signature. The client will sign through the portal.

STEP 5: Enable portal access.
Navigate to the client record and open the Portal Access section. IF portal access is not enabled, enable it. Click Send Magic-Link. The client receives an email with a link to activate their portal.

STEP 6: Send the first document request.
Navigate to the engagement created in STEP 3. Open the Document Requests tab. Click New Document Request. Add the checklist items the client needs to provide. Set a due date. Save the request. The request appears immediately on the client's To-do tab in their portal.

STEP 7: Confirm automation presets are active.
Navigate to Settings and select Automations. Confirm the Document Request Reminder preset is enabled. This sends the client an automatic reminder 3 days after the request is created if they have not uploaded anything. IF the New Client Welcome Email preset is enabled, the client already received a welcome email when their record was created.
